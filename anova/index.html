ANOVA Language

App · AAC word board

A free word board for AAC (augmentative and alternative communication). It's a web app for iPad and other tablets, and it works offline once it's installed.

What it does

  • A core word board with fixed button positions. Tapping a word speaks it and adds it to the message bar.
  • Word levels: Starter, Middle, Full, or Custom. A hidden word leaves an empty cell, so buttons never move as more words are shown.
  • A spelling keyboard (A to Z in order) with word prediction.
  • Simple read-along stories with photos or emoji. Turning a page never speaks; tapping a word or "read" does.
  • Buttons are color-coded by word type, using a modified Fitzgerald key.
  • An optional usage log. It's off by default, and it stays on the device.

How it's built

Plain HTML, CSS, and JavaScript. No build step, no frameworks, no ads, no analytics, and no network calls.

The repo holds a generic app shell with a starter board and two sample stories. Personal words, stories, photos, and recordings go in a pack. The pack is imported on the device and stays there.

About the name

ANOVA is a nod to analysis of variance, the statistics term. Language learning varies a lot from person to person. The board is built to adapt to that: adjustable word levels, custom packs, and buttons that stay put. The app itself doesn't do any statistics.

Please note

It's a free option to use at home. It is not a replacement for an evaluation by a speech-language pathologist, and it is not a medical device.

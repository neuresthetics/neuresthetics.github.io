Writing and tools

This is the Neuresthetics research. It goes back to before AI tools existed. Part of it is a book, part is a study, and part is small tools I built along the way.

Book

  • Working title

    Freedom of Necessity: God, Brain, and the Order of the Mind

    A book written axiom by axiom, in the geometric style of Spinoza's Ethics. Each entry is a definition, axiom, or proposition, and cites the entries it builds on. The first axiom is "I, a human, exist."

    The repo also holds a harness. A local open-weights model checks each entry against what it cites, and no entry can be more confident than its weakest support. The entries are unscored right now while a new checking step is built.

    Read it on GitHub: neuresthetics/freedom_of_necessity

Study

  • Neuresthetics, version 7

    V7 study

    The seventh version of the Neuresthetics study. It's a two-lane study of lawful order and remembered genius. Lane A describes what the public record shows. Lane B states a belief out loud and writes it so it can fail. Lane A doesn't depend on Lane B.

    The repo has the paper, a neurology sister paper, a data book, and one combined JSON file. Earlier versions are kept in a history folder.

    Read it on GitHub: neuresthetics/neuresthetics_v7
    Earlier version: NEUR-V6-DATA

Smaller tools

  • steel_man_s.e (Steel Man OS) A JSON pipeline that rebuilds an idea or argument into its strongest form, in stages: construct, seek, collide, join, ground, and kiln.
  • seed A small JSON kernel. Feed it into itself, or into a topic, to build a reasoning framework for that topic.
  • substance_lens A JSON framework you load into an AI chat. It treats every claim as unproven until it passes a set of logic-gate checks.
  • graphtacular A C# graph where each vertex carries a kernel that runs a strand of instructions to grow graph patterns. Built before AI.
